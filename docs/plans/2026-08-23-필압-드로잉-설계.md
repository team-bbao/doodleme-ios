# 필압 드로잉 설계 — 구현 지침

> 이 문서는 설계 전용이다. 구현 세션(Opus)은 이 문서만 읽고 코드를 짤 수 있어야 한다.
> 프로젝트 규칙: 2026년 기준 최신 Swift API 만 쓴다. Swift 6 / MainActor 기본 격리.

## 1. 왜 지금 코드로는 안 되는가

현재 상태 (`073a710` 이후):

- 잉크는 `PKInkingTool(.pen, width: 3)`, 후처리 없음.
- **애플펜슬** → `force` 가 들어오므로 필압대로 굵기가 변한다. 정상.
- **손가락** → iOS 가 `force` 를 주지 않는다 (3D Touch 폐지 이후 아이폰은
  손가락 압력을 재지 않는다). 굵기가 일정하다. 이것이 "필압이 안 된다" 로 보인다.

손가락의 필압은 **속도로 흉내** 낼 수밖에 없다 (천천히 = 두껍게, 빠르게 = 얇게).
그런데 이전 구현(`cbd0635`)은 그걸 **획이 끝난 뒤** 그림을 갈아끼우는 방식으로 해서,
손을 떼는 순간 획 모양이 눈앞에서 바뀌는 버그가 됐고 `073a710` 에서 걷어냈다.

근본 제약: **PencilKit 은 그리는 중인 획의 굵기를 밖에서 만질 API 를 열어주지 않는다.**
따라서 "그리는 동안 보이는 것 = 뗀 뒤의 것" 과 "손가락 굵기 변화" 를 동시에 하려면
**펜 입력만 PencilKit 에서 가져와 우리가 직접 받아야 한다.**

## 2. 아키텍처

`DrawingCanvas` 안에 세 겹을 쌓는다 (아래→위):

```
PKCanvasView          확정된 그림 표시 + 지우개 입력 (기존 그대로)
LiveStrokeView        그리는 중인 획 하나를 미리보기로 렌더
StrokeCaptureView     펜 모드일 때 터치를 직접 수집 (투명)
```

- 도구가 **펜**이면: `StrokeCaptureView.isUserInteractionEnabled = true`,
  `PKCanvasView.drawingGestureRecognizer.isEnabled = false`
- 도구가 **지우개**면: 반대로. 지우개는 지금처럼 PencilKit 이 처리.

핵심 트릭 — **미리보기와 확정본이 픽셀 단위로 같게 만드는 법**:
`LiveStrokeView` 는 진행 중인 점들로 `PKStroke` 하나를 만들어
`PKDrawing(strokes:[stroke]).image(from:scale:)` 로 렌더한다.
확정할 때도 **같은 PKStroke** 를 `canvas.drawing` 에 붙인다.
같은 데이터 · 같은 렌더러(PencilKit)이므로 손을 떼도 모양이 변하지 않는다.
(직접 베지어 리본을 그리면 PencilKit 렌더와 미세하게 달라 또 '팝' 이 생긴다. 금지.)

## 3. 새 파일과 책임

### `StrokeShaper.swift` (DataModel) — 순수 계산, `nonisolated`

```swift
struct StrokeShaper {
    struct Sample { let location: CGPoint; let timestamp: TimeInterval; let force: CGFloat }

    /// force > 0 인 샘플이 충분하면 힘 기반, 아니면 속도 기반으로 굵기를 매긴다.
    static func stroke(from samples: [Sample], baseWidth: CGFloat) -> PKStroke
}
```

- 속도 곡선·양끝 가늘게(taper)·이웃 평균 스무딩은 **지워진 코드를 복원**해 쓴다:
  `git show 073a710^:DoodleMe/Features/Drawing/DataModel/PKDrawing+Velocity.swift`
  (0~1800 pt/s 정규화, 1.6배~0.85배, taper 0.45 시작 — 검증된 값이다)
- `PKStrokePoint` 의 **`size` 에 굵기를 넣는다**. `force` 필드는 굵기에 안 쓰인다.
- `timeOffset` 은 `PKStrokePath(controlPoints:creationDate:)` 의 creationDate 기준 상대값.

### `StrokeCaptureView.swift` (View) — UIKit, 터치 수집

```swift
final class StrokeCaptureView: UIView {
    var onStrokeChanged: ((PKStroke) -> Void)?   // 그리는 중 매 프레임
    var onStrokeFinished: ((PKStroke) -> Void)?  // 손을 뗌
    var onStrokeCancelled: (() -> Void)?
}
```

- `touchesMoved` 에서 `event.coalescedTouches(for:)` 로 촘촘한 샘플을 얻는다.
  predicted touches 는 쓰지 않는다 (커밋본과 달라짐).
- 첫 터치 하나만 추적한다. 두 번째 손가락은 무시.
- 둥근 모서리 밖 터치 차단은 기존 `DoodleCanvasView.point(inside:)` 와 같은 식.
- 샘플마다 `StrokeShaper.stroke(from:)` 를 다시 만들어 `onStrokeChanged` 로 넘긴다.

### `LiveStrokeView.swift` (View) — 미리보기

```swift
final class LiveStrokeView: UIView {   // isUserInteractionEnabled = false
    func show(_ stroke: PKStroke)      // PKDrawing([stroke]).image 로 렌더
    func clear()
}
```

- 성능: 매번 전체 캔버스가 아니라 **획의 bounds 만** 이미지로 만들어 좌표에 맞춰 올린다.
  CADisplayLink 로 60Hz 스로틀. 획 하나짜리 렌더라 부담은 작다.

### `DrawingCanvas.swift` 수정 — 조립

- `makeUIView` 에서 세 겹을 쌓고, `updateUIView` 에서 도구에 따라 입력을 토글.
- `onStrokeFinished`:
  1. `canvas.drawing` 에 새 획을 붙인다 — 이건 **사용자 편집**이므로
     `isApplyingOurOwnChange` 가드로 델리게이트 되울림만 막고,
     `session.canvasDidChange(drawing:)` 를 직접 호출해 스냅샷 undo 에 쌓이게 한다.
  2. **같은 CATransaction 안에서** (또는 다음 runloop 에서) `LiveStrokeView.clear()`.
     순서가 어긋나면 한 프레임 비거나 겹쳐 보인다. 이 전환의 무결점이 이 작업의 전부다.

## 4. 건드리지 않는 것

- `DrawingSession` 의 스냅샷 undo/redo, `drawingRevision` 갱신 경로
- 지우개 (`PKEraserTool(.vector)`) 와 그 델리게이트 흐름
- 저장 → `PKDrawing` 직렬화 (같은 `PKStroke` 라 저장·공유·갤러리 렌더 모두 그대로)

## 5. 검증 체크리스트 (구현 후 반드시)

1. 손가락: 획을 긋고 **손을 떼는 순간 모양이 변하지 않는다** (이번 버그의 재발 확인)
2. 손가락: 천천히 vs 빠르게 → 굵기가 다르다 (시뮬레이터는 touch_path 의 dt 로 재현 가능)
3. 애플펜슬(실기기): 세게 vs 약하게 → 힘 기반 굵기
4. 지우개: 획 단위 삭제 정상
5. 되돌리기/다시하기/초기화 정상 (특히 그리는 도중 초기화)
6. 저장 후 갤러리 카드·사진 저장 이미지가 화면과 같다
7. 30초 만료가 그리는 도중 와도 크래시·유령 획 없음 (진행 중 획은 버린다)
8. 둥근 모서리 밖에서 시작한 터치는 획이 안 생긴다

## 6. 함정 미리보기

- **Swift 6 격리**: 터치 콜백은 MainActor. `StrokeShaper` 는 `nonisolated` 순수 함수로.
- `PKDrawing.image(from:scale:)` 의 scale 은 `UIScreen` 말고 `traitCollection.displayScale`.
- 확정 직후 `canvasViewDrawingDidChange` 가 한 번 되울린다 — 기존 가드 패턴 재사용.
- 미리보기 이미지 좌표는 획 bounds 원점 보정 필요 (이미지 뷰 frame = stroke bounds).
