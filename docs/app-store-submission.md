## 4. 기능 상세 (심사·설명용)

### 화면 구성

1. **갤러리 탭** — 받은 그림("너가 그린") / 내가 그린 그림을 카드 그리드로 모아 봅니다
   - 상단 "선택" 메뉴 → 프로필 지정 / 여러 장 삭제
   - 프로필 지정: 그림 한 장을 골라 프로필 사진으로 설정
   - 삭제: 여러 장 선택 후 하단 바의 휴지통으로 일괄 삭제
2. **그리기 탭** — 포스트잇을 탭하면 30초 타이머 시작
   - PencilKit 캔버스, 연필/지우개, 실행취소/다시실행
   - 30초가 끝나면 자동으로 메모 입력 단계로 전환
   - 받는 사람 이름과 30자 이내 인사말을 적고 저장
3. **카드 상세** — 카드를 탭하면 확대. 다시 탭하면 뒤집혀 메모·날짜·보낸 사람 표시
   - 공유 버튼 → 가까운 친구에게 보내기 (전체 화면)
   - 저장 버튼 → 사진 앱에 이미지로 저장
4. **가까운 친구에게 보내기** — MultipeerConnectivity 기반
   - 광고와 탐색을 동시에 수행해 주변 기기를 자동으로 발견
   - 목록에서 "전송"을 누르면 연결과 전송이 한 번에 진행
   - 가운데에는 보낼 그림이 그려진 순서대로 되살아나는 애니메이션이 반복 재생

## 5. App Review Notes (심사 메모) ★ 중요

심사자에게 반드시 전달해야 합니다. 그대로 붙여넣을 수 있게 작성했습니다.

```
[테스트 계정]
계정 시스템이 없습니다. 로그인 없이 모든 기능을 사용할 수 있습니다.

[그림 주고받기 기능 테스트 방법]
"가까운 친구에게 보내기" 기능은 MultipeerConnectivity를 사용하며,
기기 2대가 물리적으로 가까이 있어야 동작합니다.

1. 기기 2대에 앱을 설치합니다.
2. 각 기기에서 [그리기] 탭 → 화면 중앙의 메모지를 탭 → 아무 선이나 그림 →
   [다음] → 이름과 문구 입력 → [저장]
3. 각 기기에서 [갤러리] 탭 → 저장된 카드 탭 → 좌측 상단 공유 아이콘 탭
4. 두 기기 모두 이 화면을 열어두면 서로를 발견합니다.
   ("주변 사용자를 찾는중" → "1명 발견")
5. 한쪽에서 상대 이름 옆 [전송]을 누르면 상대 기기에 그림이 저장됩니다.

첫 실행 시 "로컬 네트워크 접근" 권한 요청이 표시됩니다.
이 권한을 허용해야 주변 기기를 찾을 수 있습니다.

기기가 1대뿐이면 상대를 찾을 수 없어 "주변 사용자를 찾는중" 상태가 유지됩니다.
이는 정상 동작입니다.

[네트워크]
서버와 통신하지 않습니다. 모든 데이터는 기기 내부에 저장되며,
그림 전송은 사용자가 직접 [전송]을 누를 때 기기 간에만 직접 이루어집니다.
```

## 6. 개인정보 (App Privacy) [확정 — 코드 기준]

### 수집하는 데이터: **없음 (Data Not Collected)**

근거:

- 서버·백엔드가 없습니다. 네트워크 요청 코드 자체가 없습니다
- 분석/광고 SDK가 없습니다. 외부 패키지 의존성이 0개입니다
- 계정·로그인이 없습니다
- 사용자가 입력한 이름은 기기의 `UserDefaults`에만 저장됩니다
- 그림·메모는 기기의 SwiftData 저장소에만 저장됩니다
- 그림 전송은 사용자가 명시적으로 [전송]을 눌렀을 때만, 개발자 서버를 거치지 않고 기기 간에 직접 이루어집니다

> App Store Connect의 "데이터 수집" 질문에는 **"아니요, 이 앱에서 데이터를 수집하지 않습니다"** 로 답하면 됩니다.
> (Apple 정의상 '수집'은 개발자가 데이터를 서버로 가져가는 것을 뜻합니다. 기기 내 저장과 사용자 주도의 기기 간 전송은 해당하지 않습니다.)

### 개인정보 매니페스트 (PrivacyInfo.xcprivacy) — **[블로커]**

**현재 파일이 없습니다.** 앱이 `UserDefaults`(@AppStorage)를 사용하므로
"필수 사유 API(Required Reason API)" 선언이 필요합니다.

필요한 내용:

| 항목 | 값 |
| --- | --- |
| NSPrivacyTracking | `false` |
| NSPrivacyTrackingDomains | (빈 배열) |
| NSPrivacyCollectedDataTypes | (빈 배열) |
| NSPrivacyAccessedAPITypes | `NSPrivacyAccessedAPICategoryUserDefaults`, 사유 `CA92.1` |

`CA92.1` = 앱 자신의 데이터를 앱 컨테이너 안에서만 읽고 쓰는 경우.
이 앱의 사용 방식과 일치합니다.

> 파일 위치: `DoodleMe/Resources/PrivacyInfo.xcprivacy`
> 다른 API도 쓰고 있는지 제출 전에 한 번 더 훑어보는 게 안전합니다.

## 8. 수출 규정 (Export Compliance) [결정 필요]

`MCSession`을 `encryptionPreference: .required` 로 생성합니다.
즉 **Apple이 제공하는 표준 암호화**를 기기 간 전송에 사용합니다.
자체 암호화 알고리즘은 구현하지 않았습니다.

App Store Connect에서 `ITSAppUsesNonExemptEncryption` 질문에 답해야 합니다.
일반적으로 OS 표준 암호화만 사용하는 경우 면제 대상으로 분류되지만,
**법적 신고 사항이므로 팀에서 확인 후 답하세요.**

Info.plist에 `ITSAppUsesNonExemptEncryption` 키를 미리 넣어두면
매 빌드마다 묻지 않습니다.

## 10. 제출 전 해결해야 할 것

### [블로커]

1. **개인정보 매니페스트 없음** — 6번 항목 참고. 없으면 제출이 거부됩니다
2. **앱 아이콘에 알파 채널이 있음** — 확인 결과:
   - 구조는 정상입니다. 1024×1024 단일 아이콘 방식이고 라이트/다크/틴티드 슬롯이 모두 채워져 있습니다
   - 그러나 **PNG에 알파 채널(투명도)이 포함되어 있습니다**
   - App Store 아이콘은 투명도를 허용하지 않습니다.
     업로드 시 `Invalid Image - The App Store Icon can't be transparent nor contain an alpha channel` 로 거부됩니다
   - 해결: 흰색 등 불투명 배경 위에 합성해 알파 채널을 제거한 뒤 교체
   - 참고: 다크·틴티드 슬롯이 라이트용과 같은 이미지를 쓰고 있습니다.
     거부 사유는 아니지만, 다크 모드와 틴트 모드에서 어색해 보일 수 있어 별도 제작을 권합니다
3. **SwiftData 마이그레이션 임시방편** — `LocalDataStore.makeContainer()`가
   저장소를 열지 못하면 **비우고 새로 만듭니다**.
   지금은 개발 편의를 위한 처리지만, 출시 후 스키마가 바뀌면
   **사용자 그림이 조용히 사라집니다.**
   `VersionedSchema` + `SchemaMigrationPlan`으로 반드시 교체해야 합니다.
   (코드에 ⚠️ 주석이 달려 있습니다)
4. **지원 URL 없음** — 등록 필수 항목입니다

### [결정 필요]

5. **최소 iOS 26.0** — 매우 높습니다. iOS 26 미만 기기에서는 설치조차 되지 않습니다.
   의도한 것인지, 낮출 것인지 정해야 합니다. 낮추면 다음 API를 대체해야 합니다:
   `.glassEffect`, `.buttonStyle(.glassProminent)`, `.toolbarVisibility` 등
6. **iPad 지원 여부** — `TARGETED_DEVICE_FAMILY = "1,2"` 로 iPad를 지원한다고 선언했지만
   **디자인은 iPhone 기준이고 iPad에서 확인한 적이 없습니다.**
   - iPad를 뺄 경우: `"1"` 로 변경 → iPad 스크린샷 불필요
   - 유지할 경우: iPad에서 레이아웃 확인 + iPad 스크린샷 준비 필수
   (심사자는 iPad에서도 테스트합니다)
7. **연령 등급** — 사용자가 만든 그림을 주고받습니다.
   공개 피드나 신고 기능은 없고 서로 아는 사람끼리 직접 주고받는 구조입니다.
   설문에서 사용자 제작 콘텐츠 관련 항목을 어떻게 답할지 정하세요
8. **다국어** — 현재 한국어 전용입니다. 한국 외 출시 여부를 정해야 합니다.
   문자열이 코드에 하드코딩되어 있어 String Catalog 도입이 선행되어야 합니다

### [권장]

9. **받기 전용 진입점 없음** — 공유 화면은 그림 상세에서만 열 수 있습니다.
   그림이 하나도 없는 사용자는 남의 그림을 받을 방법이 없습니다.
   앱을 처음 깐 친구에게 그림을 보내주는 상황에서 걸립니다
10. **로컬 네트워크 권한 거부 시 안내 없음** — 거부하면
    "주변 사용자를 찾는중"에서 멈춘 채 아무 안내가 없습니다
