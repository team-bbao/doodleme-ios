## 4. 기능 상세 (심사·설명용)

### 화면 구성

탭바는 왼쪽이 **그리기**, 오른쪽이 **갤러리** 입니다. 앱은 갤러리로 시작합니다.

1. **갤러리 탭** — 받은 그림("너가 그린") / 내가 그린 그림을 카드 그리드로 모아 봅니다
   - 프로필 원을 탭 → 프로필 사진 변경·삭제
   - 프로필 이름을 탭 → 이름 수정 (최대 15자)
   - **카드를 꾹 누르면** 프로필 사진 설정 / 그림 공유하기 / 삭제
   - 우상단 버튼 → 그림 공유받기 (보낼 그림 없이 받기 전용으로 열림)
2. **그리기 탭** — 포스트잇을 탭하면 30초 타이머 시작
   - PencilKit 캔버스, 연필/지우개, 되돌리기/다시하기
   - 손가락으로 그려도 긋는 속도에 따라 굵기가 변합니다
   - 30초가 끝나면 자동으로 메모 입력 단계로 전환
   - 받는 사람 이름과 30자 이내 인사말을 적고 저장
   - 앱이 백그라운드로 내려가면 타이머가 멈추고, 돌아오면 이어서 갑니다
3. **카드 상세** — 카드를 탭하면 확대. 다시 탭하면 뒤집혀 메모·날짜·보낸 사람 표시
   - 공유 버튼 → 가까운 친구에게 보내기 (전체 화면)
   - 저장 버튼 → 사진 앱에 이미지로 저장
4. **가까운 친구에게 보내기** — MultipeerConnectivity 기반
   - 광고와 탐색을 동시에 수행해 주변 기기를 자동으로 발견
   - **10초 동안 찾고**, 아무도 없으면 "주변 사용자를 찾지 못했어요" 와 다시 찾기·설정 열기
   - 목록에서 "전송"을 누르면 연결과 전송이 한 번에 진행
   - 가운데에는 보낼 그림이 그려진 순서대로 되살아나는 애니메이션이 반복 재생
     (보낼 그림이 없으면 내 프로필 그림, 그것도 없으면 기본 낙서)

## 5. App Review Notes (심사 메모) ★ 중요

심사자에게 반드시 전달해야 합니다. 그대로 붙여넣을 수 있게 작성했습니다.

```
[테스트 계정]
계정 시스템이 없습니다. 로그인 없이 모든 기능을 사용할 수 있습니다.

[그림 주고받기 기능 테스트 방법]
"가까운 친구에게 보내기" 기능은 MultipeerConnectivity를 사용하며,
기기 2대가 물리적으로 가까이 있어야 동작합니다.

1. 기기 2대에 앱을 설치합니다.
2. 각 기기에서 [그리기] 탭 → 화면 중앙의 메모지를 탭 → 아무 선이나 그림 →
   [다음] → 이름과 문구 입력 → [저장]
3. 각 기기에서 [갤러리] 탭 → 저장된 카드 탭 → 카드 위 공유 아이콘 탭
   (받기만 할 기기는 갤러리 우측 상단 버튼을 눌러도 됩니다)
4. 두 기기 모두 이 화면을 열어두면 서로를 발견합니다.
   ("주변 사용자를 찾는중" → "1명 발견")
5. 한쪽에서 상대 이름 옆 [전송]을 누르면 상대 기기에 그림이 저장됩니다.

첫 실행 시 "로컬 네트워크 접근" 권한 요청이 표시됩니다.
이 권한을 허용해야 주변 기기를 찾을 수 있습니다.

기기가 1대뿐이거나 상대가 이 화면을 열지 않았으면 10초 뒤
"주변 사용자를 찾지 못했어요" 가 표시됩니다. 이는 정상 동작입니다.
[다시 찾기] 로 다시 시도할 수 있습니다.

[네트워크]
서버와 통신하지 않습니다. 모든 데이터는 기기 내부에 저장되며,
그림 전송은 사용자가 직접 [전송]을 누를 때 기기 간에만 직접 이루어집니다.
```

## 6. 개인정보 (App Privacy) [확정 — 코드 기준]

### 수집하는 데이터: **없음 (Data Not Collected)**

근거:

- 서버·백엔드가 없습니다. 네트워크 요청 코드 자체가 없습니다
- 분석/광고 SDK가 없습니다. 외부 패키지 의존성이 0개입니다
- 계정·로그인이 없습니다
- 사용자가 입력한 이름은 기기의 `UserDefaults`에만 저장됩니다
- 그림·메모는 기기의 SwiftData 저장소에만 저장됩니다
- 그림 전송은 사용자가 명시적으로 [전송]을 눌렀을 때만, 개발자 서버를 거치지 않고 기기 간에 직접 이루어집니다

> App Store Connect의 "데이터 수집" 질문에는 **"아니요, 이 앱에서 데이터를 수집하지 않습니다"** 로 답하면 됩니다.
> (Apple 정의상 '수집'은 개발자가 데이터를 서버로 가져가는 것을 뜻합니다. 기기 내 저장과 사용자 주도의 기기 간 전송은 해당하지 않습니다.)

### 개인정보 매니페스트 (PrivacyInfo.xcprivacy) — **[완료]**

`DoodleMe/Resources/PrivacyInfo.xcprivacy` 로 추가했고 Release 번들에 들어가는 것을 확인했습니다.
앱이 `UserDefaults`(@AppStorage)를 쓰므로 "필수 사유 API" 선언이 필요했습니다.

담은 내용:

| 항목 | 값 |
| --- | --- |
| NSPrivacyTracking | `false` |
| NSPrivacyTrackingDomains | (빈 배열) |
| NSPrivacyCollectedDataTypes | (빈 배열) |
| NSPrivacyAccessedAPITypes | `NSPrivacyAccessedAPICategoryUserDefaults`, 사유 `CA92.1` |

`CA92.1` = 앱 자신의 데이터를 앱 컨테이너 안에서만 읽고 쓰는 경우.
이 앱의 사용 방식과 일치합니다.

> 파일 타임스탬프·디스크 공간·부팅 시각·키보드 API 는 쓰지 않는 것을 코드에서 확인했습니다.
> 외부 패키지 의존성도 없어 서드파티 매니페스트를 합칠 일이 없습니다.

## 7. 권한 사용 목적 [확정]

| 권한 | 문구 | 사용처 |
| --- | --- | --- |
| 로컬 네트워크 (`NSLocalNetworkUsageDescription`) | "가까이 있는 친구와 그림을 주고받기 위해 주변 기기를 찾습니다." | 주변 기기 발견·연결 |
| 사진 추가 (`NSPhotoLibraryAddUsageDescription`) | "그린 첫인상 그림을 사진 앱에 저장하기 위해 사용합니다." | 카드 상세의 저장 버튼 |
| Bonjour 서비스 (`NSBonjourServices`) | `_doodleme._tcp`, `_doodleme._udp` | MultipeerConnectivity |

- 사진 권한은 **추가 전용(add-only)** 입니다. 사진을 읽지 않습니다
- 카메라 권한은 QR 기능 제거와 함께 삭제했습니다
- 위치·연락처·마이크·알림 등은 사용하지 않습니다

## 8. 수출 규정 (Export Compliance) [결정 필요]

`MCSession`을 `encryptionPreference: .required` 로 생성합니다.
즉 **Apple이 제공하는 표준 암호화**를 기기 간 전송에 사용합니다.
자체 암호화 알고리즘은 구현하지 않았습니다.

App Store Connect에서 `ITSAppUsesNonExemptEncryption` 질문에 답해야 합니다.
일반적으로 OS 표준 암호화만 사용하는 경우 면제 대상으로 분류되지만,
**법적 신고 사항이므로 팀에서 확인 후 답하세요.**

Info.plist에 `ITSAppUsesNonExemptEncryption` 키를 미리 넣어두면
매 빌드마다 묻지 않습니다.

## 10. 제출 전 해결해야 할 것

### [해결됨]

1. ~~개인정보 매니페스트 없음~~ → `PrivacyInfo.xcprivacy` 추가, Release 번들 포함 확인
2. ~~앱 아이콘 알파 채널~~ → 흰 배경 합성으로 제거.
   컴파일된 카탈로그에서 1024 아이콘 `Opaque = True` 확인
   - 남은 권장 사항: 다크·틴티드 슬롯이 라이트용과 같은 이미지입니다.
     거부 사유는 아니지만 다크·틴트 모드에서 어색할 수 있어 별도 제작을 권합니다
3. ~~SwiftData 마이그레이션 임시방편~~ → `PostSchemaV1` + `PostMigrationPlan` 도입.
   저장소를 열지 못해도 **지우지 않고 이름만 바꿔 격리**하도록 바꿨습니다.
   기존 저장소가 그대로 열리는 것과 데이터가 보존되는 것을 확인했습니다

4. ~~받기 전용 진입점 없음~~ → 갤러리 우상단이 **그림 공유받기** 버튼입니다.
   그림이 없어도 받기 전용으로 열 수 있고, 가운데에는 프로필이나 기본 낙서가 그려집니다
5. ~~로컬 네트워크 권한 거부 시 안내 없음~~ → 10초 뒤 못 찾으면 권한을 짚어 주고
   **설정 열기** 버튼을 답니다. 찾기 자체가 시작되지 못하면 권한을 콕 집어 말합니다
